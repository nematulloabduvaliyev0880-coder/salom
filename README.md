# Ne`matullo — Kino sayt

Bu loyiha mahalliy demo sahifa: Ne`matullo kinoteatri bosh sahifasi (HTML + CSS).

Qanday ishlatish:

1. Loyihani klonlash yoki nusxalash.
2. Rasmlarni `img/` papkasiga joylang (hero.jpg, dune.jpg, beekeeper.jpg, oppenheimer.jpg, lotr.jpg, blackwidow.jpg, collection1.jpg, collection2.jpg, collection3.jpg, flash.jpg, originals.jpg, bigbang.jpg, vampire.jpg, mission.jpg, guardians3.jpg, avatar2.jpg, spiderman.jpg).
3. Mahalliy serverda ko‘rish uchun faylni brauzerda oching yoki `live-server` kabi vositadan foydalaning.

Git va GitHubga yuborish (misol):

```bash
git init
git branch -M main
git add .
git commit -m "Initial commit: Ne`matullo site"
# GitHub'da repository yarating, so'ng quyidagi buyruqni bajarib yuboring:
# git remote add origin https://github.com/USERNAME/REPO.git
# git push -u origin main
```

Agar xohlasangiz, men GitHub repozitoriyasini yaratishda yordam bera olaman (token yoki `gh` CLI kerak bo‘ladi).
